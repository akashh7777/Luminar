React JS
  - is a JS library for building user interface
  - follows "view" aspect in MVC architecture
  - developed at Facebook and released to world on 2013
  - use in web applications such as whattsapp web , Facebook web , spotify web
  - ideal for building single-page applications(SPAs) and interactive web applications
  - it is component based and allows building reusable UI components


Single Page applications
   
   - SPA is a web application or website that interact with user by dynamically rewriting the current page rather than loading  entire new page from server
   - In SPA initial HTML, CSS & JS are loaded once during initial page load and when a routing occurs it rewrites the content with new content

Key characteristics

    - No Page Reloads  -> They do not trigger a full page reload when navigating between different views or sections of the application. Instead, they update the content dynamically, providing a smoother and faster user experience.
    
    - Dynamic loading -> They fetch and update only the necessary data or components when the user interacts with the application, reducing the amount of data transferred and improving performance. 
    
    - Client-side Routing  -> They use client-side routing to manage navigation within the application. This means that the routing logic is handled on the client side, allowing for seamless transitions between different views without requiring a full page reload.


Features of React JS

    - JSX -> JavaScript Syntax Extension for writing HTML inside JavaScript
    - Components -> The building block of any React application
    - State and props -> state handles dynamic data . Props pass data between components
    - Hooks -> Allow the use of state and lifecycle methods in functional components
    - Virtual DOM -> Efficient re-rendering mechanism

  Virtual DOM
    - It is a lightweight representation of the actual DOM.
    - It is a copy of the actual DOM and is kept in memory.
    - When a component's state or props change, React updates the virtual DOM first, and then compares it with the previous version of the virtual DOM using a process called "DIFFING."
    - React then calculates the most efficient way to update the actual DOM based on the differences between the two virtual DOMs, and only updates the parts of the actual DOM that have changed. This process is called "RECONCILIATION."
    - This approach allows React to minimize the number of direct manipulations to the actual DOM, which can be slow and inefficient, and instead perform updates in a more optimized manner. By using the virtual DOM, React can improve the performance of web applications by reducing the number of direct manipulations to the actual DOM.

routing in React JS
  - React itself doesnot provide a built-in routing system.
  - React Router DOM is a popular library used to implement routing/navigation in React web applications.

  rules for routing in React JS
  
    1. Install React Router DOM using npm or yarn.
    2. Wrap your application in a <BrowserRouter> component to enable routing.
    3. Use the <Routes> component to define your application's routes.
    4. Use the <Route> component to specify the path and the corresponding component to render for each route.
    5. Use the <Link> component to create navigation links between different routes in your application.

Hooks in React JS

  - Hooks are functions that allow you to use state and other React features in functional components.
  - They were introduced in React 16.8 to enable functional components to have state and lifecycle methods, which were previously only available in class components.

  Commonly used hooks

    - useState -> allows you to add state to functional components
    - useEffect -> allows you to perform side effects in functional components, such as fetching data or subscribing to events
    - useContext -> allows you to access the context value in functional components
    - useRef -> allows you to create a mutable reference that persists across renders
    - useMemo -> allows you to memoize expensive calculations and avoid unnecessary re-renders
    - useCallback -> allows you to memoize functions and avoid unnecessary re-creations of functions on every render


Rules for calling hooks in functional Component 

  -Import hooks from react package
  -Call hooks at the top level of the functional component, not inside loops, conditions, or nested functions.
  -hooks cannot be conditionally called, they should be called in the same order on every render.
  -hooks start with "use" prefix to indicate that they are hooks and follow the naming convention of camelCase.
  -Introduced in React 16.8, hooks are only available in functional components and cannot be used in class components.


props in React JS

  - Props (short for properties) are a way to pass data from a parent component to a child component in React.
  - They are read-only and cannot be modified by the child component.
  - Props allow you to customize the behavior and appearance of a component based on the data passed to it.

State in React JS

  - State is a built-in object that allows components to manage and track their own data.
  - It is mutable and can be updated using the setState() method in class components or the useState() hook in functional components.
  - State changes trigger re-renders of the component, allowing the UI to reflect the updated data.
